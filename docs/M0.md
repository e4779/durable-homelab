## Решения для M1 (черновик)

1. **settings-manager** → свой config.json (модели z.ai + корпоративный провайдер,
   httpProxy из pi-настроек) — ~100-150 строк вместо 1533.
2. **model-runtime** → минимальный runtime поверх pi-ai: список моделей из конфига,
   stream + abort. 1032 строки оригинала несут каталоги/OAuth/remote-каталог —
   нам нужен только resolve+stream. Оценка: 200-400 строк.
3. **CodingTools** уже пакетизирован: `@earendil-works/pi-durable/tools` — bash/edit/
   read/write НЕ портировать, взять пакетные.
4. **resource-loader/skills/system-prompt** → заглушки: секции из наших extensions
   вместо загрузчика. Перенести позже, если понадобятся скиллы.
5. **http-dispatcher** → перенести как есть (113 строк), прокси критичен.
6. **TUI** → отложить; M2 делает web-сёрфейс. pi-tui/proper-lockfile выпадают
   из deps до появления TUI.

Оценка M1: ~500-800 строк своего кода вместо ~10k vendored.
